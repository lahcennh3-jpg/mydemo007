promotion requirements have been satisfied and documented.

1. Which specialization gap remains?
2. Is it already covered by existing project evidence?
3. Is it conditional, alternative, covered or genuinely deferred?
4. Does it address a target-market need?
5. Does it require a new project?
6. Does the expected value justify the maintenance burden?
7. What evidence would demonstrate mastery?

length or project count.
