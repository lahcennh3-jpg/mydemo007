# Phase 22 — Six-Capstone Portfolio Map

## Integrity rule

Phase 22 repackages existing engineering evidence.

It does not create new technical findings and does not retroactively
change the provenance of earlier work.

Assisted work remains labelled assisted.

Independent work is labelled independent only when its independent
verification gate has passed.

Phase 21 Action 21.17 remains:

`BLOCKED_INDEPENDENT`

That limitation must remain visible until independently satisfied.

# Portfolio completion rule

A capstone may move beyond `NOT_YET_PACKAGED` only after it contains:

1. source-evidence references;
2. problem/context definition;
3. architecture or system context;
4. threat model;
5. test methodology;
6. reproducibility instructions;
7. attack interpretation;
8. defense/remediation interpretation;
9. verification evidence;
10. limitations;
11. provenance labels;
12. sanitization review.

No capstone is complete merely because supporting Phase 0–21 material
exists.
