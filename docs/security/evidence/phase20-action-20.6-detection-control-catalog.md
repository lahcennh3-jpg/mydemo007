# Phase 20 — Detection Control Catalog

The initial Phase 20 detection catalog covers twelve security domains/signals:

1. authentication failure;
2. cross-user authorization;
3. tenant isolation;
4. unauthorized RAG retrieval;
5. memory isolation;
6. agent privilege;
7. tool authorization;
8. MCP authorization;
9. sensitive-data export;
10. abuse/resource controls;
11. infrastructure privilege;
12. workload identity.

These are detection requirements.

A catalog entry does not mean the corresponding production detection already
exists.

Batch B maps these requirements to observable Onyx surfaces and tests
detectability.
