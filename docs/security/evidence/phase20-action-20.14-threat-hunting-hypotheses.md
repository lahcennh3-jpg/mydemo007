# Phase 20 — Threat-Hunting Hypotheses

Phase 20 defines **12** local/synthetic threat-hunting hypotheses.

Coverage:

- authentication;
- cross-user authorization;
- cross-tenant access;
- RAG retrieval;
- memory;
- agent privilege;
- tool authorization;
- MCP trust;
- sensitive-data export;
- resource abuse;
- workload privilege;
- cross-event identity correlation.

These are investigation hypotheses and required telemetry questions.

They do not establish production SOC hunting coverage.
